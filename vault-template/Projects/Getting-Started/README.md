# איך עובדים עם המוח השני

המוח השני הוא תיקייה של פתקים ש-Obsidian מציג ו-Claude Code קורא וכותב.
כל פרויקט מקבל תיקייה אחת עם דף בית (`README`), וכל מסמך שנוצר בעבודה נשמר בה ומקושר אליו.
כך Claude זוכר מה נעשה, גם בשיחה חדשה ובעוד חודש.

## מה אפשר לבקש מ-Claude
- "תפתח פרויקט חדש בשם X" — נוצרת תיקייה, דף בית ושורה במפת הפרויקטים.
- "תשמור את זה במוח השני" — המסמך נשמר בפרויקט הנכון ומקושר.
- "מה המצב בפרויקט X?" — Claude קורא את דף הבית ואת המסמכים האחרונים ועונה.
- "נמשיך בשיחה חדשה" — Claude כותב מסמך העברה, ומדביקים בשיחה החדשה שורה אחת.
- "סיום סשן" — Claude סוגר קצוות, מעדכן את המוח השני ומסכם מה למד.
- "כיול" — Claude עובר על השיחה, מוצא איפה טעה או מה ביקשת אחרת, ושומר את זה לפעם הבאה.
- "תסדר את המוח השני" — בדיקת קישורים שבורים, פתקים יתומים ומקומות לא נכונים.

## איפה מה נמצא
- [[Projects/Projects-MOC|מפת הפרויקטים]] — כל הפרויקטים במקום אחד.
- `_library` — תבניות וידע שחוזר על עצמו.
- `_archive` — פרויקטים שהסתיימו (לקריאה בלבד).
