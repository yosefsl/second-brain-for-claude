## Second brain (Obsidian)
The owner keeps a second brain: an Obsidian vault at `{{VAULT}}`, the long-term memory of every project.
- When work touches a project, read it first (skill `second-brain`): `Projects/Projects-MOC.md` → the project `README.md`
  → its newest notes. Answer from the files.
- Every deliverable is saved there in the same turn (skill `vault-save`). The vault rules are `{{VAULT}}/CLAUDE.md`.
- Facts about the work go into the vault; lessons about how to work with the owner go into your memory (skill `calibrate`).
- Ending a session: skill `session-handoff`. Tidying: skill `vault-tidy`. Tool: `~/.second-brain/bin/brain`.
